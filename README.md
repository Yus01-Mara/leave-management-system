# Leave Management System (Laravel)

## Setup Instructions

1. Clone project
- git clone https://github.com/YOUR_USERNAME/leave-management-system.git

2. Install dependencies
- composer install
- npm install

3. Copy environment file
- cp .env.example .env

4. Generate key
- php artisan key:generate

5. Configure database in .env

6. Run migration
- php artisan migrate

7. Run server
- php artisan servea
